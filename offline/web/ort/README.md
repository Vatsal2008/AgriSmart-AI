# onnxruntime-web 1.22.0 (WebAssembly build)

These three files are the unmodified WebAssembly build of [onnxruntime-web](https://www.npmjs.com/package/onnxruntime-web)
1.22.0, kept here so the offline app runs the models with no internet:

- `ort.wasm.min.js`
- `ort-wasm-simd-threaded.mjs`
- `ort-wasm-simd-threaded.wasm`
